- [SMARTCHOICE](https://bilalmuhammad41.github.io/left-brain-right-pixels/llm/projects/smartchoice.md): Insurance comparison for car, bike, health, and travel cover in Pakistan (2024)
- [SEEDINOV](https://bilalmuhammad41.github.io/left-brain-right-pixels/llm/projects/seedinov.md): Studio site for custom software, AI products, and shipped case studies (2024)
- [THIS IS DIGITAL](https://bilalmuhammad41.github.io/left-brain-right-pixels/llm/projects/this-is-digital.md): A digital agency landing page recreation (2022)
- [MY TODO](https://bilalmuhammad41.github.io/left-brain-right-pixels/llm/projects/my-todo.md): Minimal task manager built with vanilla JavaScript (2023)
